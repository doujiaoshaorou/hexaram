海斗助手 0.9.3 修正当前连胜／连败统计，并统一使用 Windows 安装版。

### 下载与升级

- 下载 `Hexaram-0.9.3-win-x64-setup.exe` 安装包。从本版起，后续版本统一以安装版发布和更新。
- 已使用安装版：关闭旧程序后运行安装包覆盖升级，保留原安装目录、配置、战绩和桌面／开始菜单快捷方式。也可在「设置 → 关于我们」检查更新，下载后确认重启安装。
- 旧便携版首次迁移：关闭旧程序，把安装包放在旧 EXE 所在目录再运行。安装器复制配置、战绩、设备 ID 和旧版归档，保留原资料；安装目录已有资料不覆盖。迁移后从「海斗助手」快捷方式启动。

### 连胜／连败修正

- 只从同模式最新一场正常对局开始往前连续计数，遇到相反结果立即结束，早先的连胜／连败不计入。
- 标签数字、触发判定和说明共用同一最近窗口，修正 50 场规则读取窗口外场次显示数字的问题。
- 自定义规则按对局时间倒序判断，并使用自身的队列与窗口生成标签数字。

更新清单统一指向签名安装包，不再提供便携版附件。提供安装包签名、源码和 SHA256 校验文件。
