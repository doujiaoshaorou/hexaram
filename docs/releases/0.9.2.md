海斗助手 0.9.2 新增 Windows 安装版，并开放完整的玩家标签规则编辑。

### 下载与安装

- 推荐下载 `Hexaram-0.9.2-win-x64-setup.exe`。默认文件夹为英文 `Hexaram`，安装时创建「海斗助手」桌面及开始菜单快捷方式。
- 首次从便携版迁移：关闭旧程序，将安装包放在旧 EXE 所在目录再运行。安装器复制配置、战绩、设备 ID 和旧版归档；原资料保留，目标目录已有资料不覆盖。
- 继续使用免安装版可下载 `Hexaram-0.9.2-win-x64.exe`，放回原程序目录运行。

### 更新

- 安装版下载并验证签名安装包，在当前安装目录覆盖升级，保留快捷方式、配置和战绩，成功后重启。
- 便携版仅下载签名裸 EXE 并在原位置更新。两种安装方式分别选包；安装包不会自动替换便携版。
- 默认自动检查更新、手动下载与重启；选人或对局进行中不允许安装更新。
- 0.9.0 / 0.9.1 便携用户可直接更新至本版；要切换为安装版，需要按首次迁移步骤手动安装一次。

### 标签规则

- 25 个内置标签与自定义标签共用可编辑条件树；内置规则可复制为自定义规则。
- 支持单局 AND、候选组 OR、有效比例、最低命中场数、总量 KDA、英雄类型分布及胜率阈值。
- 长期与近期窗口、最低有效样本独立配置，保留现有自定义标签及默认开关。

同时修正了正式打包仍连接开发服务器的问题。提供源码、两类更新签名、更新清单与 SHA256 校验文件。
