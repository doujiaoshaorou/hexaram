# 0.8.1 历史对局详情修复

2026-10-07。针对游戏开始后点击历史战绩无反应的反馈。

## 修改

- 我的战绩、查询和共用战绩卡入口直接在主窗口弹出已加载的十人详情。打开操作不等待 LCU、localStorage 或原生窗口创建，不依赖当前游戏阶段。
- 复用现有详情组件，保留强化、装备、MVP/SVP、AI 复盘及关闭操作。
- 弹窗提供“独立窗口”入口。已有独立窗口先恢复最小化，再显示并聚焦。
- 原生窗口创建错误和兜底显示错误不再按成功处理；界面提示错误，同时保留当前详情。
- 不修改历史数据、评分、标签或游戏进程；不上传 GitHub。

## 原因调查与验证边界

旧点击路径依赖独立 WebView 创建；创建失败只记录日志并标记成功，打开已有窗口也未恢复最小化。这些是代码中确认的缺口，但尚不能确定用户本次遭遇的是哪一个原生窗口故障。

19 项针对性前端测试通过：详情窗口 12 项、战绩列表 5 项、新详情弹窗 2 项。覆盖当前缓存直接打开、切换与关闭、存储写入不可用、已有窗口恢复、创建与显示失败反馈、快速重复点击和就绪兜底。Vue 类型检查及 debug/release 构建通过，既有 Rust unused 和 Vite 分包警告仍存在。

本次原生 QA 桥的脚本与截图请求持续超时，重启 QA 实例后仍未恢复，因此没有把真实游戏进行中的界面点击列为已通过。自动测试验证的是应用打开流程；实际游戏场景仍需使用新版确认。没有启动或结束英雄联盟对局，也未调用收费 AI。

源码包排除个人档案、配置、密钥、调试数据、依赖和构建目录。
