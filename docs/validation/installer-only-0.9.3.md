# 0.9.3 安装版与当前连续胜负验证

日期：2026-10-11。

## 变更

- 当前连胜／连败只从同模式最新正常对局开始连续计数，遇到相反结果结束；判定、标签数字和说明使用相同时间顺序、筛选和窗口。
- 后续 Windows 构建只导出 NSIS 安装包，发布脚本与 GitHub Actions 不再分发裸 EXE。latest.json 只有指向签名安装包的 platforms 条目，不再包含 portable 条目。
- 新客户端统一选择签名安装包并通过 NSIS 覆盖升级，拒绝旧的便携更新缓存；保留安装目录内的配置、战绩和快捷方式。
- AGENTS.md 记录安装版发布约定；README、发布说明与开发文档同步更新。

## 结果

- Rust command 模块 187 项通过、2 项依赖签名成品／网络的测试默认跳过，包含 28 项标签测试和安装包选择／旧缓存拒绝测试。
- 更新界面、顶部更新提示及标签编辑器共 20 项前端测试通过。
- TypeScript 类型检查与 Vite 生产构建通过；Tauri CLI 正式生成 0.9.3 NSIS 安装包，文件版本为 0.9.3，构建输出目录只有 setup.exe。
- PowerShell 脚本语法解析、GitHub Actions actionlint 及 Git diff 空白检查通过。
- 隔离安装测试通过：英文默认目录、旧配置／战绩／设备 ID／归档复制、桌面和开始菜单快捷方式、跨版本覆盖升级、重复安装、卸载保留数据及中文／空格路径。
- 模拟 GitHub 发布测试通过：安装包真实签名、仅安装版附件、更新清单、最终 tag URL、完整回下载校验，以及上传内容损坏时保持草稿、不发布。

安装测试使用隔离目录、独立注册表名称、独立快捷方式目录、独立测试可执行文件／进程名和合成数据。发现原测试进程名未隔离后已修正并重新验证，防止静默安装测试按原进程名关闭用户程序。未验证真实玩家的应用内升级操作。保留既有 Rust 未使用代码和前端分包警告。

此前全量 Rust 库测试的 3 项旧配置／缓存名称断言失败与本次变更无关。完整 npm check 在当前本地环境仍因没有 npm 无法启动，Clippy 未安装；全局 Rust／JSON 格式检查有既有差异。以上明确列出的针对性检查均已通过，不把它们视为全量门禁通过。
