# 0.9.2 安装版验证（2026-10-11）

新增 Windows x64 NSIS 安装包 `Hexaram-0.9.2-win-x64-setup.exe`。默认按当前用户安装，桌面和开始菜单使用「海斗助手」快捷方式，目标为固定安装目录内的 `hexaram.exe`。

同日调整：首次安装的默认文件夹及选择磁盘时追加的文件夹统一为英文 `Hexaram`；界面、卸载信息和快捷方式名称仍为「海斗助手」。使用与 Tauri CLI 2.11.4 对应的官方 NSIS 模板，只分离目录名。已有安装位置与用户指定路径继续沿用。

首次迁移时，将安装包放到旧便携 EXE 旁边并关闭旧程序。安装器按项复制配置、战绩、设备 ID 和旧版归档；源文件保留，安装目录已有数据不覆盖。安装版更新只选本仓库签名 setup 附件，便携版只选签名裸 EXE；旧更新缓存按便携包处理，跨形态缓存拒绝安装。安装版调用 NSIS `/P /R /UPDATE /D=安装目录`，保留快捷方式和数据，并在成功后重启。

验证结果：

- Vue 类型检查及前端正式构建通过；更新逻辑和 Header 定向测试 17 项通过。原 Header 测试缺少 `backgroundCheck` mock，已按现有接口修复。
- 更新后端 5 项测试、便携版签名/替换/安装形态相关 15 项测试通过；网络 fixture 默认忽略。
- Windows 正式 EXE 与实际 NSIS 安装包构建成功。两类成品均使用现有 Hexaram 更新密钥签署，并通过真实成品的签名校验和内存篡改拒绝验证。
- `tests/installer-smoke.ps1` 使用真实生成的 NSIS 模板、正式 EXE 和迁移 hooks，替换为独立测试产品标识，重定向桌面/开始菜单到项目内测试目录。使用合成资料验证首次安装、Unicode 与空格路径、递归归档复制、0.9.2 → 合成 0.9.3 的覆盖升级、同版本重装和卸载。
- 上述测试确认快捷方式仍指向同一路径，升级保留已修改配置、战绩和安装形态标记，卸载移除程序/快捷方式并保留数据；原便携资料仍在。测试注册项已清理，合成文件保留在 `.tools/installer-qa-*` 便于复查。
- 调整后的安装器复验通过：无 `/D` 参数的首次安装落在隔离用户目录下的 `Hexaram` 文件夹；显式指定含中文和空格的路径仍按指定路径安装，迁移、升级、重装和卸载检查通过。

隔离测试跳过 WebView2 安装，不启动游戏或正式安装的应用。本次没有执行已发布 GitHub 版本之间的联网自动升级；也没有安装到用户实际桌面。成品安装包已放在原便携程序目录，供首次安装与迁移。
