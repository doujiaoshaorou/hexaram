# 0.9.0 验证记录

日期：2026-10-07。范围：项目入口、版本检查、签名下载与安装入口、发布流程和文档整理。

## 已完成

- Windows 正式构建通过，包含 Vue 类型检查与 Vite 构建。
- 前端定向回归 25 项通过：更新状态与开关、历史详情窗口、详情弹窗。
- 更新后端 3 项单元测试通过：数字版本排序、上游/伪装域名拒绝、无签名版本只提供手动下载。
- 既有便携更新 15 项测试通过，覆盖签名、篡改拒绝、替换与回滚。
- 使用本项目新签名密钥验证实际可执行文件；篡改后校验失败。
- 原生窗口检查关于页布局、版本信息、更新记录折叠及自动下载开关写入本机配置。
- 实测 GitHub 匿名 API 返回 403 时，Release 附件索引能成功返回公开版本信息。

## 发布约束与限制

- 更新只读取 doujiaoshaorou/hexaram 正式 Release。下载与安装均验证内置公钥签名；私钥、个人配置和战绩不进入公开源码或附件。
- 自动检查默认开启，自动下载默认关闭。下载后需用户确认重启；选人或游戏进行中拒绝安装。
- 0.8.1 没有此更新功能，首次升级须手动下载 0.9.0。完整跨版本自动安装仍需下一正式版本验证；当前已验证替换/回滚单元测试与签名文件。
- 现有未使用代码和 Vite 分包告警仍存在，不影响本次构建；未将其描述为零告警构建。
- 开发与验证资料移到 docs/；用户更新说明以 GitHub Releases 为准。
